# 0.9.1 릴리스 준비 검증 (2026-10-08)

사용자 승인으로 기존 release-0-9-1 작업을 인계했다. 변경은 버전 0.9.1과 릴리스 문서다.
`make release-check`는 GoReleaser 2.18.2로 통과했다.
`make quality-check`는 format, lint, security, build, install audit를 통과했으나
unit 단계의 CE parity golden guard에서 실패했다. 설치 CE `15-g5f482526`과
fixture `498-gf540f972` 불일치다. 기준 master `71f1d44`의 `go test ./tests/parity/...`에서도
동일 실패를 재현했다. 다른 unit 패키지 실패는 없고 fixture 변경도 없다.
기존 ISSUE-44의 별도 재설계 범위이며 릴리스 변경이 악화시키지 않은 baseline 실패로 기록한다.

중단 이후 target인 `make test-integration-quality test-e2e-only coverage-critical-check`는
모두 통과했다. 핵심 coverage는 gitcmd 59.6%, repository 59.3%, reposync 61.0%,
workspacecli 65.4%로 선언된 floor 이상이다. 전체 quality-check 성공으로 보고하지 않는다.
외부 태그·릴리스·cask 설치 결과는 실제 게시 후 확인해야 한다.
